# 02 — Research Copilot

**Status: Architecture / Prototype**

A research workflow designed to turn a question into a structured evidence package.

### Workflow

```
QUESTION → PLAN → SOURCES → EXTRACT → CLAIMS → EVIDENCE → REPORT → REVIEW
```

### Trust controls
- source provenance
- claim-to-evidence mapping
- explicit uncertainty
- human review
- reproducible research records

### Intended client work
Market research, technical research, competitor analysis, literature reviews and structured intelligence reports.

No fabricated findings or citations are acceptable.
