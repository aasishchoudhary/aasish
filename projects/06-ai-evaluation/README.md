# 06 — AI Reliability & Evaluation Lab

**Status: Research / Prototype**

A measurement framework for AI systems.

### Evaluation dimensions
- task completion
- tool selection
- invalid actions
- latency
- recovery
- human intervention
- regression
- cost

### Evidence ladder

```
CLAIM → SPECIFICATION → IMPLEMENTATION → TEST → MEASUREMENT → VALIDATION
```

The project deliberately avoids publishing impressive-looking metrics without a reproducible measurement method.
